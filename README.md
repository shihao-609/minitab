# 质量管理系统 QMS

基于 Streamlit 的类 Minitab 质量管理 Web 应用。

## 功能模块

- **SPC 控制图** — X-bar R / X-bar S / I-MR / P / NP / C / U
- **过程能力分析** — Cp, Cpk, Pp, Ppk
- **帕累托图 & 直方图** — 含箱线图
- **量具 R&R 分析** — 交叉型平均值-极差法
- **正态性检验** — Shapiro-Wilk, Anderson-Darling
- **散点图 & 回归** — 线性回归分析

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```
